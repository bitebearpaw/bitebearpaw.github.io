河內塔 Tower of Hanoi

用遞迴，把大問題變成小問題
國九　資訊科技｜遞迴單元

回顧上次學過的遞迴：費氏數列

int fib(int n) {
    if (n <= 2)        // 終止條件
        return 1;
    return fib(n-1) + fib(n-2);
}

1, 1, 2, 3, 5, 8, 13, 21, …

遞迴的兩個要素

  1. 終止條件：小到可以直接回答
  2. 縮小問題：呼叫自己，但問題變小

今天要看一個「不用遞迴，很難想」的問題。

故事一個古老的傳說

神廟裡有 3 根鑽石柱，其中一根套著 64 片金盤，由大到小疊起來。

僧侶依照規則，日夜不停地把金盤搬到另一根柱子上。

傳說：搬完的那一刻，世界就會毀滅。

※ 謎題由法國數學家 Édouard Lucas 於 1883 年發明，傳說也是他編的。

規則遊戲規則

  1. 一次只能搬 一片
  2. 只能拿 最上面 的那片
  3. 大盤子不能壓在小盤子上

目標：把全部盤子從 A 搬到 C，
而且步數 越少越好。

A 起點　　B 輔助　　C 目標

為什麼？ 我們來想一想搬盤子的過程。

關鍵先只想「最大的那一片」

最大的盤子要搬到 C，搬的那一刻：

  • 它必須在 A 的 最上面
  • C 必須是 空的

那其他 n − 1 片 在哪裡？

→ 一定全部疊在 B！

拆解搬 n 片 = 三個步驟

1n−1 片：A → B

借用 C 當輔助

2最大那片：A → C

只要 1 步

3n−1 片：B → C

借用 A 當輔助

步驟 ① 和 ③ 是什麼？ → 就是「少一片」的河內塔！　這就是 遞迴。

對照河內塔也有遞迴的兩要素

費氏數列 fib(n)河內塔 hanoi(n)
終止條件n ≤ 2 時，回傳 1n = 1 時，直接搬過去
縮小問題fib(n−1) + fib(n−2)hanoi(n−1) → 搬最大 → hanoi(n−1)
呼叫自己幾次2 次2 次

遞迴的思考方式：不用想清楚每一步，
只要 相信「n−1 片的問題會被解決」，再處理好最大的那片。

程式寫成 C++

#include <iostream>
using namespace std;

void hanoi(int n, char src, char dst, char tmp) {
    if (n == 1) {                       // 終止條件
        cout << 1 << ": " << src << " -> " << dst << endl;
        return;
    }
    hanoi(n-1, src, tmp, dst);                    // ①
    cout << n << ": " << src << " -> " << dst << endl; // ②
    hanoi(n-1, tmp, dst, src);                    // ③
}

int main() {
    hanoi(3, 'A', 'C', 'B');
}

src：起點柱
dst：目標柱
tmp：輔助柱

注意 ① 和 ③ 裡，
三根柱子的角色互換了。

追蹤hanoi(3, A, C, B) 是怎麼執行的？

hanoi(3, A, C, B) ├─ hanoi(2, A, B, C) ① │ ├─ hanoi(1, A, C, B) → ❶ 1號 A→C │ ├─ ❷ 2號 A→B │ └─ hanoi(1, C, B, A) → ❸ 1號 C→B ├─ ❹ 3號 A→C ② └─ hanoi(2, B, C, A) ③ ├─ hanoi(1, B, A, C) → ❺ 1號 B→A ├─ ❻ 2號 B→C └─ hanoi(1, A, C, B) → ❼ 1號 A→C

共 7 步，正好是最少步數！

總結今天學到什麼？

  • 河內塔：把 n 片的問題，拆成兩個 n−1 片的問題 + 1 步
  • 遞迴兩要素：終止條件（n = 1 直接搬）＋ 縮小問題（呼叫 hanoi(n−1)）
  • 每一層呼叫，柱子的角色會互換（起點、目標、輔助）
  • 最少步數 2n − 1：每多一片，工作量約變 2 倍
  • 指數成長非常驚人：64 片要 5846 億年

遞迴的精神：相信小問題會被解決，專心處理眼前這一步。

解答練習參考答案

1

1號 A→B，2號 A→C，1號 B→C（共 3 步）

2

4 片（偶數）：先搬到 B；5 片（奇數）：先搬到 C

3

5 號盤只搬 1 次；1 號盤搬 16 次（第 k 號盤搬 2n−k 次）

4 
long long cnt = 0;   // 全域計數器（不要取名 count，會和 std::count 衝突）
void hanoi(int n, char src, char dst, char tmp) {
    if (n == 1) { cnt++; return; }
    hanoi(n-1, src, tmp, dst);
    cnt++;
    hanoi(n-1, tmp, dst, src);
}
int main() { hanoi(10, 'A', 'C', 'B'); cout << cnt; }   // 印出 1023
