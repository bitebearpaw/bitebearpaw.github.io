費式數列 fib(n)：函數呼叫時，記憶體裡發生了什麼？

0, 1, 1, 2, 3, 5, 8, 13 …　每一項 = 前兩項相加。按「播放」或「下一步」，看電腦怎麼一步步算出來。

📦 比喻：每呼叫一次函數，電腦就在記憶體的「堆疊（Stack）」上疊一個新盒子，盒子裡放這次呼叫自己的變數（n、a、b）。 只有最上面的盒子在工作，下面的盒子都在「暫停等答案」。做完了，盒子就被拿走，答案交給下面那個盒子。

在 n 欄位輸入 0～10 後按 Enter 或「設定」。鍵盤：← → 上一步／下一步，空白鍵 播放／暫停

  


  

    
🔑 每個盒子都有自己的 n
fib(4) 裡的 n 是 4，fib(3) 裡的 n 是 3。它們是不同的變數，放在不同的盒子裡，互不干擾。這就是「區域變數」。

    
⏸ 呼叫 = 暫停並等待
fib(4) 執行到 a = fib(3) 時會停在那一行，直到 fib(3) 的盒子做完、被拿走，才帶著答案繼續往下。

    
🛑 一定要有終止條件
if (n <= 1) return n; 讓盒子不再往上疊。沒有它，盒子會一直疊到記憶體爆掉（Stack Overflow）。

    
🐢 遞迴會重複計算
看看呼叫樹裡的紅虛線：fib(2)、fib(1) 被算了好幾次。n 越大，重複越嚴重，這也是之後要學「用陣列記住答案」的原因。
