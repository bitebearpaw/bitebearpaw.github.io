# 🐻 熊熊學資訊

網站：https://bitebearpaw.github.io/

動手玩，才會懂 — 國中資訊科技的互動教學網頁與投影片。每個工具都是單一 HTML 檔，不依賴外部資源，下載後可離線使用。

## 目錄結構

```
index.html          首頁（工具清單）
fib/
  index.html        費式數列：函數呼叫與記憶體（遞迴動畫）
memory/
  index.html        記憶體尋寶（記憶體階層互動網頁）
hanoi/
  index.html        河內塔互動網頁
  slides.html       河內塔教學投影片
<新工具>/
  index.html
```

## 新增一個工具

1. 建立資料夾（用英文小寫，例如 `binary/`），把工具網頁存成 `index.html`
2. 在首頁 `index.html` 的 `TOOLS` 清單加一筆
3. commit 並 push，約 1 分鐘後網站就會更新

各別 repo 的舊工具（cs、image-widget、sound-widget）仍維持原網址，首頁直接連過去。
